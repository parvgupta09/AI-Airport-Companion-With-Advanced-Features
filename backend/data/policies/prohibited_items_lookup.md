# Master Prohibited Items Lookup Matrix

*This matrix dictates exact compliance for baggage sorting.*

| Item Category | Cabin (Hand Luggage) | Hold (Checked Luggage) | Strict Conditions / Exceptions |
| :--- | :--- | :--- | :--- |
| **Power Banks / Lithium Batteries** | **YES** | **NO** | Max 100Wh. Max 2 per passenger. Must be carried in cabin. |
| **Lighters (Standard/Bic)** | **YES** | **NO** | Max 1 per person. Must be carried ON the person (in pocket), not in the bag. |
| **Lighters (Torch/Blue Flame)** | **NO** | **NO** | Strictly prohibited everywhere on airport property. |
| **E-Cigarettes / Vapes** | **YES** | **NO** | Must remain in cabin bag. Use is strictly prohibited. |
| **Aerosol Deodorant / Hairspray** | **YES** | **YES** | Cabin: Must be <100ml. Hold: Must have protective cap to prevent accidental release. |
| **Knives / Box Cutters** | **NO** | **YES** | Any blade length is banned from the cabin. Must be sheathed securely in hold luggage. |
| **Scissors** | **YES** | **YES** | Cabin: Blades must be less than 6cm from the fulcrum. If >6cm, must be checked. |
| **Alcoholic Beverages** | **YES** | **YES** | Cabin: Only if purchased Airside/Duty-Free in a sealed STEB. Hold: Must be unopened retail packaging. |
| **Tools (Screwdrivers, Wrenches)** | **NO** | **YES** | Any tool longer than 6cm must go in hold luggage. Power tools must have batteries removed. |
| **Self-Defense Sprays (Pepper Spray)**| **NO** | **NO** | Strictly prohibited. Will be confiscated and may result in police questioning. |
| **Safety Matches** | **YES** | **NO** | 1 small packet permitted on the person. "Strike-anywhere" matches are strictly forbidden. |
