# Security Lockout & Gate Closure Policies

## 1. Hard Cut-Off Timelines
Automated e-gates control access to the secure areas. There are no exceptions to the following deadlines:
- **Security Checkpoint Entry:** Scanners will reject boarding passes **45 minutes** before the scheduled departure time.
- **Boarding Gate Closure:** Aircraft doors and gate bridges are sealed exactly **20 minutes** prior to departure.

## 2. The Lockout Procedure (Missed Cut-off)
If an e-gate flashes red and displays "SECURITY LOCKOUT":
1. **Do Not Argue:** Airport security personnel cannot override the automated lock. 
2. **Baggage Offload:** The system automatically notifies the baggage handlers that you have missed the security cut-off. Your checked luggage will be actively offloaded from the aircraft for safety reasons.
3. **Re-routing:** Turn back and proceed to your airline’s Landside Ticketing Desk to discuss rebooking.

## 3. "Gate No-Show" vs. "Security Lockout"
- If you pass security but fail to reach the boarding gate before the T-20 minute cut-off, you are marked as a "Gate No-Show."
- In this event, you must wait at the gate for an airline agent to issue you an "Airside Escort Pass" so security can escort you back out to the public arrivals area.
